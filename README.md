# Jueky Portfolio — GitHub Pages

1. Buat repository baru di GitHub, misalnya `portfolio`.
2. Upload `index.html`, `project.html`, `style.css`, `script.js`, dan folder `images`.
3. Buka Settings → Pages.
4. Source: Deploy from a branch → pilih `main` → `/ (root)` → Save.
5. Website akan tersedia di alamat GitHub Pages milikmu.

## Mengganti isi
- Edit judul/deskripsi di `index.html`.
- Edit data project di bagian `const projects` pada `project.html`.
- Ganti kotak `ADD PROJECT IMAGE` dengan gambar project asli.
- Email contoh `yourname@email.com` perlu diganti.
